# MIAFEx publication reporting

The shared presentation pipeline adapts the supplied final Code Smell figure
layout, visible-text helpers and publication style. It consumes MIAFEx's own
cached observations and retains MIAFEx algorithm identities, including
`MaCRO-DE-t-v2`. No Code Smell data, optimizer logic or manuscript aliases are
imported.

## Presentation configuration

Edit these existing/new settings in `main_best.py` before parsing arguments:

```python
PLOT_RUN_AGGREGATION = "best"  # existing: best, worst, mean
PLOT_GLOBAL_ESTIMATOR = "knn"
PLOT_GLOBAL_METRIC = "accuracy"  # accuracy, precision, recall, f1
FIGURE_LANGUAGE = "en"         # en, es
PLOT_COLOR_PALETTE = "dark_classic"
STATISTICAL_METRIC = "f1"       # accuracy, precision, recall, f1
```

CLI overrides are `--plot-global-estimator`, `--plot-global-metric`,
`--figure-language`, `--plot-color-palette`, and `--statistical-metric`.
The sole run-aggregation setting remains `PLOT_RUN_AGGREGATION`.
Palettes: `dark_classic`, `deep`, `muted`, `tab20_dark`, `dark2`, `paired`, `accent`.
The fixed method registry and deterministic extension keep colors stable across
subsets, ordering, classifiers and figures; transfer variants share base colors.

`best` selects the positional run with minimum final `FitRuns`; `worst` selects
maximum final `FitRuns`. Accuracy, Precision, Recall, F1, selected features,
runtime and convergence all use that same run. `mean` averages the stored run
arrays arithmetically. Figure 01 averages those representatives across datasets;
its classifier rows retain all selected classifiers. Distributions always use
the actual cached runs, regardless of representative selection. Scientific
summary tables and cache signatures do not consume these presentation settings.

The first active proposed family in the configured optimizer order supplies the
reference method (`MaCRO-DE`, `MaCRO-DE-t`, `MaCRO-DE-t-v2`, or `DSADE`). The
completed EXP607 preview selects `MaCRO-DE-t-v2`; EXP608's currently configured
`MaCRO-DE-t` is highlighted when reporting its completed results. If no proposed family is active, the first
observed algorithm is the reporting reference. Radar/convergence draw it last
with stronger lines; distribution/bar/heatmap views use a stronger outline.
All competitors and numerical values remain intact.

5. `05_convergence_por_dataset_<classifier>.png`
6. `06_heatmap_<metric>_<classifier>.png`
7. `07_violin_<metric>_<classifier>.png`
8. `08_global_<metric>_distribution.png`
9. `09_global_features_runtime_tradeoff.png`

Additional non-heatmap diagnostics go under `individual/`. Statistical plots go
under `statistics/`; their Holm heatmap is an inferential output, separate from
the one principal numbered heatmap. No redundant dataset/classifier/algorithm
heatmaps are generated by the shared pipeline.

Radar retains MIAFEx's absolute selected/original feature ratio, reading only
the feature CSV headers for original dimensions. Missing dimensions are omitted
and never invented. Convergence uses validated stored histories. Its lower-right
inset shows the final quarter of iterations; the lowest final-fitness band
defines its vertical range. Missing/invalid histories are reported, and the
affected panel's inset is skipped. Histories are never reconstructed.

Box/violin plots retain real distributions, medians, arithmetic mean markers
and centered mean numbers. They contain no raw or jittered observations. Box
whiskers show the complete observed min/max range.

## Matched-block statistics

1. Compute the arithmetic mean of independent completed runs within each
   dataset × classifier × algorithm cell.
2. Retain identical dataset/classifier blocks complete for every algorithm in
   the intended comparison family. Record missing/incomplete blocks explicitly.
3. Rank within each complete block, averaging ties; rank 1 is best.
4. Compute Friedman when there are at least two complete blocks and three
   algorithms, and the tie correction is defined.
5. Compute paired two-sided Wilcoxon on the same complete blocks for every
   unordered pair; apply Holm over that entire prespecified all-pairs family.

Exact signed ranks are used for nonzero untied differences up to 50 blocks;
otherwise the reported normal approximation uses Wilcox zero removal and no
continuity correction. All-zero differences produce W=0, p=1. Insufficient
blocks produce no inference. Alpha is 0.05. Non-significance does not establish
equivalence, and rank differences are not effect sizes. Classifiers on the same
dataset share observations; the text report records this dependence and the
Wilcoxon symmetry assumption.

Files under `Results/.../statistics/`:

- `statistical_summary.csv`
- `pairwise_wilcoxon_holm.csv`
- `matched_block_means.csv`
- `omitted_blocks.csv`
- `statistical_report.txt`

Figures under `Figures/.../statistics/`: average rank, reference comparisons,
Holm significance heatmap, and matched-block distributions (when estimable).
Statistical aggregation is independent of `PLOT_RUN_AGGREGATION`.

## Safe report-only invocation

Use the configured project interpreter and completed cache settings matching
the selected EXP. To report the completed EXP607 configuration explicitly,
independently of any subsequent edits to the execution defaults:

```bash
.venv/bin/python -B main_best.py --report-only --exp-id 607 \
  --report-output-root /tmp/miafex-report-review \
  --optimizers MaCRO-DE-t-v2 DE JADE SHADE PSO GWO WOA HHO DBO RUN FOX \
  --plot-global-estimator knn --plot-global-metric accuracy \
  --figure-language en --plot-color-palette dark_classic --statistical-metric f1
```

This existing guarded path appends `Figures/EXP607/full_repN/` and
`Results/EXP607/full_repN/` below the alternate report root. Existing source
figures, results, caches, checkpoints and features remain untouched. The guard
blocks optimizer/model execution and writes outside the new report destinations.
The report manifest records presentation settings, expected main filenames,
skipped outputs and zero optimization calls. It never computes missing science.
Report-only reads the selected EXP's completed caches; the execution-only
cross-EXP reuse setting does not silently substitute EXP607 data for EXP608.

`--report-only --figures-only` retains the existing figure-only `full/` layout;
use an alternate `--report-output-root` to preserve historical figures. The
legacy `generate_seven_global_charts` entry point delegates to the nine-figure
renderer for normal completed-result reporting as well.

Quick validation: `tests/test_publication_reporting.py` exercises representatives,
language/metric/classifier switching, all palettes, 5/11/14 algorithms, highlighting,
stored-curve insets, full distributions, one principal heatmap, matched blocks,
Friedman/Wilcoxon/Holm and guarded zero-execution dispatch. It uses synthetic
fixtures and completed caches; no full experiment is required.
